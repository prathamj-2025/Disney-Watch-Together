# Watch Together prototype

A clickable desktop prototype for **Watch Together**, a concept feature for a streaming service. Couples and families who live apart can watch the same title in sync while they chat, talk, or video call.

Team 10: Pratham Jain, Parth Chavan, Apoorva Kamath, Yuqi Zhang

## Demo flow

1. Click any title, then the blue **Watch Together** button.
2. Pick **Couple mode** or **Family mode**, then **Create session**.
3. Watch people join with the code, then **Start watching together**.
4. Pause, rewind, or skip for everyone. Use chat, reactions, mic, and camera in the side panel.
5. Click **Full screen**. A floating live video window stays on top, like a minimized Zoom call. Move it to any corner or minimize it.

Partner activity is simulated for the demo.

## Logo

The supplied teal Disney+ logo is stored as `assets/logo.png` and appears in the main navigation, the home hero, and the browser tab. Its transparent background lets the original teal artwork display cleanly on the prototype's dark background.

## Run locally

Open `index.html` in a browser. No build step or install is needed.

## Deploy

This is a static site. On Vercel, import the GitHub repo, choose the **Other** framework preset, and deploy with the default settings.
